## Главные выводы

1. **Задача решаема в той постановке, что в SPEC.** Текстовые задачи этого уровня модели решают хорошо; главная точка отказа — рисунки, и SPEC их уже исключил ([01](01-feasibility.md)).
2. **Генерация даёт брак.** В лучших системах генерации школьных задач все критерии выполняются примерно для 2/3 задач — проверка и ретраи обязательны ([01](01-feasibility.md)).
3. **Три совпавших ответа от Claude — слабое доказательство.** Ошибки моделей одного производителя коррелируют. Самый сильный ход — программная проверка ответа и единственности решения для вычислимых тем ([05](05-verification.md)).
4. **LLM сами не сообщают о неоднозначности**, если их прямо не попросить. Промпту Скептика нужен явный чек-лист ([05](05-verification.md)).
5. **Сложность для ребёнка ≠ сложность для модели.** Уровень и сложность лучше считать формулой (Эло) по реальным ответам, а LLM-Методисту оставить педагогические решения внутри коридора. Первую гипотезу честно проверять сравнением с простым правилом ([06](06-adaptive-learning.md)).
6. **Дистракторы от LLM менее правдоподобны, чем от людей.** Лучше помогают похожие задачи с размеченными ловушками и реальные ответы детей ([04](04-distractors-misconceptions.md)).
7. **Технический баг в SPEC:** `temperature: 0` на Sonnet 5 вернёт ошибку 400 ([07](07-models.md)).
8. **Юридический риск в SPEC:** дообучение на ответах Claude без письменного разрешения нарушает условия Anthropic; реальные задачи конкурсов из открытых наборов — только некоммерческие и без обучения ИИ ([02](02-contest-domain.md), [08](08-finetuning-data.md)).
9. **Бюджет занижен:** реалистичная цена попытки ~$0.15–0.23 против цели < $0.10 за задачу ([07](07-models.md)).
10. **Однообразие — системное свойство всех LLM**, с ним нужно бороться явно ([03](03-problem-generation.md)).
11. **Локальные модели 2026 года сильны в решении задач** (gpt-oss-20b в 16 ГБ), поэтому во второй фазе первыми переводить решателя и проверяющего, Генератор — последним ([07](07-models.md)).
12. **Идеи задач для эталонов есть на все пять уровней сложности.** Лёгкие — задачи повышенной трудности из советских учебников и открытые наборы текстовых задач (GSM8K и SVAMP под MIT); средние — советские книги занимательных задач (Перельман и Игнатьев уже в общественном достоянии) и кружковые сборники; трудные — архивы олимпиад для 4–7 классов. Идеи задач авторским правом не охраняются, поэтому годится любой источник, если формулировка наша ([12](12-task-sources.md)).
13. **Олимпиадная ниша для младших классов почти пуста, но канал ограничивает возраст.** Массовые продукты учат школьной программе или решают домашку; единственный сильный олимпиадный продукт для 6–13 лет — Beast Academy с конечным банком задач и только на английском. При этом Claude пускает с 18 лет, ChatGPT — с 13 и запрещает приложениям ориентироваться на младших, а продавать подписку внутри чата нельзя: пользователь плагина — родитель или тренер. Наша уникальность — не «ИИ-репетитор», а конвейер «генерация плюс проверка плюс модель ученика»; продвинутый уровень нашей проверкой не закрывается ([13](13-competitors.md)).

## Метод и ограничения

- Поиск через веб-поиск; первоисточники (arXiv, ACL, Nature, документация, страницы конкурса) — через загрузку страниц.
- Страницы пересказывала вспомогательная модель, поэтому **цифры стоит сверять с оригиналом** перед важными решениями. Там, где источник вторичный (блоги, обзоры), это помечено.
- Часть статей недоступна (платный доступ, PDF), по ним использованы аннотации.
- Юридические разделы — обзор источников, не юридическая консультация.
- Название международного конкурса, который изучался в [02](02-contest-domain.md), из репозитория убрано по решению автора (D36): прототип на него не ориентируется. Факты сохранены, ссылки с названием конкурса в адресе удалены.
- Прямых работ про генерацию *олимпиадных* задач для 1–4 классов не нашлось; выводы по генерации сделаны по близким областям — школьным текстовым задачам и синтетическим математическим датасетам.
